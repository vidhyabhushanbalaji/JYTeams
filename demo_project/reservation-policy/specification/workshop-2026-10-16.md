Status: Agreed · Owner: Sofia Mendes · Last updated: 2026-10-20

## Agenda

3. What a warehouse needs to see (30 min).
4. Rules we cannot agree today (30 min).

## Agreed

- Reservation starts at payment authorisation, 30 minutes, extended to 60 on capture (RSV-01, RSV-02).
- Allocation happens at wave build; the reservation is not strengthened before then (RSV-03).
- Every release carries a reason code, and the code list is closed for this release (RSV-17).
- Quarantine is subtracted before availability is published, in the ingestor, not downstream (RSV-13).
- Split shipments each get their own reservation and their own promise (see split shipments).

## Not agreed

| Question | Positions | Outcome |
| :--- | :--- | :--- |
| Bulky items: reserve at order or at booking? | Trading: at order. Fulfilment: at booking, because a failed two-person booking costs £46 to rebook | Deferred; two-option paper to steering 2026-12-03 (RSV-06) |
| Collection hold: 3 or 5 days? | Stores: 5. Contact centre: 3, because uncollected stock blocks the shelf | Deferred to Elena and Sofia by 2026-11-27 (RSV-11) |
| Should a manual hold release reservations? | Marcus wants an emergency release; Nadia warns it is an oversell path | No: hold stops new reservations, never releases existing ones (RSV-18) |

## The moment that changed the design

Dermot described the quarantine pallet from August. Nadia's reaction, recorded verbatim: "So the
number was wrong for nine days and nobody could see it?" That exchange is why availability is
computed centrally with quarantine as an explicit input, rather than in each consumer.
