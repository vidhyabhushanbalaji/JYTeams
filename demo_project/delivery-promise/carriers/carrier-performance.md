# Carrier Performance

Status: Agreed · Owner: Gavin Shore · Last updated: 2026-11-13

The monthly carrier scorecard: on-time, damage, loss, cost and volume, with the actions that follow
each number. The point of the scorecard is that the promise is only as good as the carrier behind it,
so the same measures appear in the promise accuracy report.

## Targets

| Carrier | On-time target | Damage target | Action if missed two months |
| :--- | :--- | :--- | :--- |
| Parcelway | 96 % | ≤ 0.2 % | Contract review, SLA credit |
| Northline | 93 % | ≤ 1.2 % | Capacity or packaging remediation plan |
| Swiftbox | 97 % | ≤ 0.1 % | Locker availability review |

Northline's on-time figure is measured **within the booked slot**, which flatters it. Measured
against the date promised at checkout, it is 58 %, because the slot itself is often outside the
promise. Both numbers are shown to steering; the second is the one that matters to a customer.

## What the numbers do not show

| Hidden cost | Estimate per month | Where it appears |
| :--- | :--- | :--- |
| Rebookings (Northline) | £4,416 | Delivery cost |
| Customer service calls about late parcels | £3,100 | Contact centre |
| Goodwill vouchers | £6,800 | Trading |
| Return-to-depot (Swiftbox) | £790 | Carrier invoice |
| Redelivery after failed access | £2,700 | Carrier invoice |

Adding those to the headline cost per parcel gives a truer picture: Parcelway costs £4.31 per order
all-in, Northline £28.60. That comparison drives the service recommendation rules in checkout.
