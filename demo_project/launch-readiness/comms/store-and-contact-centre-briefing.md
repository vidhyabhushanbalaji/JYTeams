# Store and Contact Centre Briefing

Status: Draft · Owner: Elena Vasquez · Last updated: 2026-11-13

The two groups who will be asked about the promise face to face. Both get a task card rather than a
document, because nobody reads a document during a shift.

## Store task card

The card is one side of A5 and covers four jobs:

| Task | What to do | What changed |
| :--- | :--- | :--- |
| Pick a collection order | Scan the item, confirm the pick | Orders arrive as tasks, not printouts |
| Cannot find the item | Use the cancel reason on the handheld | Do not phone the customer |
| Item not collected in 5 days | Do nothing; the system releases it | No manual stock correction |
| Customer asks about a delivery date | Read the date from the order screen | Do not quote "3–5 days" |

The fourth line is the one the contact centre and stores must share: a colleague quoting a range
after the platform has given a date undermines the whole exercise.

## The five questions stores will ask

| Question | Answer |
| :--- | :--- |
| What if the handheld is broken? | Use the store PC; the task is in the same list |
| What if the customer is at the counter before we pick? | Pick it there and then; the task can be completed at the counter |
| What if we only have a damaged one? | Cancel with the damage reason, do not substitute |
| Can we still correct stock manually? | Yes, but through the adjustment screen with a reason |
| What if the customer wants to change the item? | Treat as a new order; do not edit the pick |

The fourth question is important. Manual corrections are allowed; silent ones are not.

## Contact centre briefing

| Session | Content | Duration |
| :--- | :--- | :--- |
| 1 | Why the promise changed, and what it says | 45 min |
| 2 | The agent screen: date, fallback reason, shipment grouping | 60 min |
| 3 | Scenarios: date changed, item not found, fallback | 60 min |
| 4 | Escalation and what not to promise | 30 min |

Agents get a practice environment with ten scripted orders, including one fallback and one split. Each
agent completes at least eight of the ten before launch day, and the completion list is signed off by
the contact centre lead.

## What agents must never do

| Never | Why |
| :--- | :--- |
| Quote a range when the system shows a date | Creates a second promise |
| Promise compensation | Only Marcus can authorise |
| Tell a customer a carrier is at fault | Commercially self-harming |
| Manually release a reservation | Creates oversell |
| Read out a postcode-level reason | Confusing, and often wrong |

## Measurements

| Measure | Target |
| :--- | :--- |
| Agents completing the practice set | 60 of 60 |
| Stores acknowledging the task card | ≥ 170 of 184 |
| Calls about "what date" after launch | Falling within two weeks |
| Agent confidence (self-rated, post-training) | ≥ 4 of 5 |
