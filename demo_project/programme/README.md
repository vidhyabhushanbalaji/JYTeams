# Programme Documentation

Status: Agreed · Owner: Priya Raman · Last updated: 2026-11-13

Project Truestock is run from the programme office. This folder holds the plan, the governance
rules and the fortnightly status report, so that "who is doing what, by when, and what is in the
way" has one answer rather than four.

## What lives here

| Folder | Holds | Read it when |
| :--- | :--- | :--- |
| [plan](./plan/) | Milestones, workstreams, dependencies, resourcing | You need a date or an owner |
| [governance](./governance/) | Steering group, decision rights, change control, RAID | You need a decision or want to raise a risk |
| [status](./status/) | Fortnightly status reports | You want the current picture without a meeting |

## Cadence

| When | What | Who |
| :--- | :--- | :--- |
| Monday 09:30 | Workstream leads stand-up, 30 minutes | All leads |
| Wednesday 14:00 | Integration and data surgery | Dan, Nadia, vendor engineers |
| Thursday 10:00 | Steering group, fortnightly | Sponsors and leads |
| Friday (fortnightly) | Status report published here | Programme office |

## Escalation in one line

Anything that moves a milestone date, changes a policy rule, or adds more than 15 days of effort
goes to the steering group through [change control](./governance/change-control.md); everything
else is decided by the named owner in [decision rights](./governance/decision-rights.md).
